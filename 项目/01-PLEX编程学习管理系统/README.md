# PLEX 编程学习管理系统

> 个性化资源生成与多智能体协作的 Python 智教平台

面向 Python 初学者，围绕学习者画像、资源生成、路径推荐、学习反馈与教师审核构建教学闭环，引入七维动态画像、多智能体协同与多模态学习资源生成机制。

- 角色：队长
- 工作：项目总体规划、产品架构设计、智能体工作流、接口规范与核心功能开发
- 成果：中国软件杯大学生软件设计大赛全国三等奖
